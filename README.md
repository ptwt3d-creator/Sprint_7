# Sprint 7

## Структура проекта и описание файлов

### Архитектура и хелперы
`api.py` (`ApiRequests`) — класс-клиент API. Содержит статические методы для отправки HTTP-запросов (`GET`, `POST`, `DELETE`). Все методы изолированы от тест-кейсов и обернуты в аннотации `@allure.step` для детализации отчетов.

`data.py` — конфигурационный файл. Содержит класс `TestUrl` со всеми эндпоинтами (ручками) бэкенда и класс `TestData` со статическим словарем дефолтных параметров для создания заказа.

`helpers.py` (`Helpers`) — вспомогательный класс. Хранит методы для генерации случайных строк, динамического расчета даты доставки на завтрашний день и экспресс-генерации полезной нагрузки (payload) для регистрации.

`conftest.py` — глобальный файл конфигурации PyTest. Хранит фикстуры предусловий (`Setup`) и очистки тестовых данных после прогона (`Teardown`), включая удаление курьеров и сборку параметров заказов.

### Тестовые наборы (Test Suites)
`test_registration_new_courier.py` — тесты ручки создания курьера: успешная регистрация курьера (201), проверка обязательности полей логина/пароля (400), необязательность имени и обработка создания дубликата (409).

`test_login_courier.py` — тесты ручки авторизации: успешный вход (200), валидация наличия ID курьера в теле ответа, проверки отсутствия логина/пароля (400), а также попытки входа под несуществующим аккаунтом (404).

`test_order.py` — параметризованный набор тестов на создание заказа. Проверяет корректность генерации номера трека при различных комбинациях цвета самоката (черный, белый, оба цвета, либо без выбора).

`test_list_order.py` — тесты ручки получения списка заказов: проверяет успешность запроса и валидирует присутствие ключевого поля `orders` в теле JSON-ответа.

## Инструкция по запуску тестов

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3. Находясь в корневой директории проекта, установите все необходимые зависимости и внешние библиотеки одной командой:
```bash
pip install -r requirements.txt
```

### 2. Локальный запуск тестов
Для стандартного выполнения всех тестов выполните команду:
```bash
pytest
```

Если вы хотите запустить тесты с автоматическим перезапуском в случае нестабильности или таймаутов учебного стенда сервера (требуется плагин `pytest-rerunfailures`), используйте:
```bash
pytest --reruns 3 --reruns-delay 2
```

## Генерация отчетов Allure

Все тестовые сценарии размечены аннотациями `@allure.suite`, `@allure.title` и `@allure.description` для создания красивой документации.

1. Сбор результатов тестирования:
   Запустите тесты с указанием папки для сохранения результатов Allure:
   ```bash
   pytest --alluredir=allure_results
   ```

2. Просмотр графического отчета:
   Для генерации веб-интерфейса отчета и его автоматического открытия в браузере выполните команду:
   ```bash
   allure serve allure_results
   ```
