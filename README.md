# Sprint_7

## Описание настроек и конфигураций

- `url` — Содержит класс с базовыми URL и все эндпоинты (ручки) API Яндекс Самоката для курьеров и заказов.

## Описание тестовых данных и хелперов

- `testdata` — Содержит класс со статическими методами для генерации случайных текстовых строк, динамического расчета даты доставки, а также метод быстрой регистрации курьера для предусловий тестов авторизации.

## Описание тестов

- `test_registration_new_courier` — Проверки ручки создания курьера: успешная регистрация (в том числе без необязательного поля имени), проверка обязательности логина и пароля. Проверка уникальности логина при создании дубликата.

- `test_login_courier` — Проверки ручки авторизации курьера: успешный вход в систему с валидацией формата ID в ответе, а также проверка обязательности логина, пароля и вход под несуществующей учетной записью.

- `test_order` — Параметризованный, проверка успешной отправки запроса и получения номера трека при различных цветовых комбинациях самоката.

- `test_list_order` — Проверка ручки получения списка заказов: проверка структуры JSON-ответа (корректности типов данных и наличия всех обязательных полей).

## Описание дополнительных файлов

- `requirements.txt` — Список внешних зависимостей и библиотек необходимых для автотестов.
